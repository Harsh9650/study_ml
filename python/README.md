# Python Basics

This folder contains scripts demonstrating fundamental Python functionalities. It serves as a reference for beginners and those looking to brush up on core Python concepts.

## 📂 Contents

- **Data Types & Variables** – Understanding integers, strings, lists, dictionaries, and more.  
- **Control Flow** – Using loops (`for`, `while`) and conditional statements (`if-else`).  
- **Functions & Modules** – Writing reusable code with functions and importing modules.  
- **File Handling** – Reading and writing files in Python.  
- **Error Handling** – Using `try-except` blocks to manage exceptions.  
- **Object-Oriented Programming (OOP)** – Classes, objects, and inheritance basics.
